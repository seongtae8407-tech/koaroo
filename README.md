# 구영코아루 55평형 3D 평면도

`55평형 단위세대평면도`의 치수선(가로 22,780 mm × 세로 12,130 mm)을 읽어 만든 웹용 3D 평면도입니다.
설치 없이 브라우저에서 바로 열립니다. 3D 라이브러리는 [three.js](https://threejs.org/) 0.160.0을 CDN에서 불러옵니다.

## 기능

- **3D / 평면 보기** 전환
- **회전 각도** 0° · 90° · 180° · 270° 고정, **회전 멈추기**
- **확대 / 축소** 버튼 (키보드 `+` `-`, 휠, 핀치도 가능)
- **구조 방향**: 실제 집(상하 반전) ↔ 도면 원본
- **길이 재기**: 바닥 두 점 사이 거리 표시, 끄면 측정선 자동 삭제
- **방 목록**: 방별 치수와 면적(㎡ · 평), 실내·발코니 합계, 누르면 해당 방 강조
- 가구 배치 예시, 방 이름 표시, 벽 낮게 보기(1 m) 켜고 끄기
- 거실 발코니 2곳 확장 반영

## 실행 방법

### 내 컴퓨터에서
`index.html`을 더블클릭해 브라우저로 열면 됩니다. (인터넷 연결 필요: three.js와 글꼴을 CDN에서 받습니다.)

### GitHub Pages로 공개
1. 이 폴더의 파일을 저장소에 올립니다.
2. 저장소 **Settings → Pages**에서 **Source: Deploy from a branch**, 브랜치 `main`, 폴더 `/ (root)`를 선택합니다.
3. 잠시 뒤 `https://<사용자이름>.github.io/<저장소이름>/` 주소로 열립니다.

## 구조 수정하기

모든 치수는 `index.html` 안의 `<script type="module">`에 mm 단위로 들어 있습니다.
좌표는 **도면 원본 기준**(x는 오른쪽, y는 아래쪽, 왼쪽 위 모서리 근처가 0)이며, 화면의 상하 반전과 회전은 자동으로 처리됩니다.

| 데이터 | 내용 | 형식 |
|---|---|---|
| `ROOMS` | 방 바닥 모양과 이름 | `poly`: 꼭짓점 목록, `dims`: 표시용 가로·세로, `kind:'balcony'`면 발코니 |
| `WALLS` | 벽 | `[x1, y1, x2, y2, 종류, 두께, [[시작, 폭, 'door' 또는 'open'], ...]]` |
| `FURN` | 가구 | `[x0, y0, x1, y1, 높이(m), 색, 띄움 높이(m)]` |

벽 종류는 `solid`(막힌 벽), `glass`(방과 발코니 사이 창, 턱 낮음), `outer`(바깥 창, 턱 0.9 m)입니다.

예) 침실2 문 위치를 옮기려면 `WALLS`에서 `[5380,4100,5380,8580,'solid',120,[[250,850,'door']]]`의 `250`(벽 시작점에서 문까지 거리)을 바꿉니다.

## 참고

- 사진으로 찍은 도면의 치수를 읽어 만든 **근사 모델**입니다. 위치에 따라 ±20 cm 정도 차이가 날 수 있습니다.
- 방 크기와 면적은 **벽 중심선 기준**이라 실제 안목 치수나 전용면적보다 조금 큽니다.
- 문 위치와 창 크기는 도면과 평면 이미지를 보고 배치한 것이라 실제와 다를 수 있습니다.
- 가구는 배치 예시입니다.
